# 맵 이미지 내려받기 (18장)

이미지 서버가 자동 다운로드를 막고 있어서(Cloudflare 봇 확인), 브라우저에서 직접 저장해 주세요.

1. 아래 **이미지 열기**를 눌러 브라우저에서 엽니다.
2. 이미지를 우클릭 → **다른 이름으로 이미지 저장**
3. 이 폴더(`image/Maps/`)에 **파일 이름 칸의 이름**으로 저장합니다. 확장자(.png/.jpg/.webp)는 그대로 둬도 됩니다. 예: `krakoa.png`
4. `npm run data`를 실행하면 1280px WebP로 줄여 `public/images/maps/`에 넣고, 화면에 자동으로 나타납니다.
