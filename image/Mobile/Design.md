## 1. 디자인 콘셉트 — "손안의 전적 사이트"

| 참고 | 가져올 것 | 도감에서 쓰는 곳 |
|---|---|---|
| ① 챔피언 선택 그리드 | 촘촘한 정사각 초상화 그리드, 아이콘만으로 된 역할 필터 바, 선택 칸은 파란색, 잠금 같은 작은 상태 배지 | 영웅 목록, 팀 빌더 영웅 선택 |
| ② OWTICS.GG 통계 | 어두운 표, **수치마다 다른 색 막대**(지표 = 주황, 픽 = 파랑, 밴 = 빨강, 승률 = 초록/빨강), 역할별 그룹 줄, 증감(+/−) 막대, 오른쪽 상단 필터 칩 | 티어 화면, 영웅 상세 통계, 맵 메타 |

**모바일 + 다크로 정한 이유**
- **한 손 조작:** 게임 중이나 대기 시간에 휴대폰으로 빠르게 확인하는 상황을 기준으로 잡았습니다. 자주 누르는 버튼은 화면 아래쪽에 둡니다.
- **다크 테마:** 두 참고 이미지 모두 어두운 배경이고, 게임 화면과 오가도 눈이 덜 피로합니다. 투명 배경 영웅 이미지도 어두운 배경에서 윤곽이 잘 보입니다.
- **숫자는 막대로:** 작은 화면에서는 숫자만 나열하면 비교가 어렵습니다. 이미지 ②처럼 숫자 아래에 얇은 막대를 붙이면 한눈에 크기를 비교할 수 있습니다.

| 필터 칩 | 카드 오른쪽 위 "그랜드마스터 & 챔피언" 작은 칩 | 출처/기준 칩: "커뮤니티 통계 · 10/15" |
| 범례 | 표 아래 "픽률 ■ 픽 ■ 밴", 티어 색 범례 | 막대 색 범례를 화면 하단에 항상 표시 |
| 숫자 글꼴 | 고정폭 느낌, 굵게 | 숫자는 `tabular-nums` + 굵게 |

## 3. 레이아웃 시스템 (375px 기준)

```
┌───────────────── 375 ─────────────────┐
│ 상단 바 56px  [로고]        [🔍] [⚙]   │  ← 고정, 스크롤 시 배경 블러
├───────────────────────────────────────┤
│ 좌우 여백 16px                          │
│ ┌─ 콘텐츠 343px ─────────────────────┐ │
│ │                                     │ │
│ └─────────────────────────────────────┘ │
├───────────────────────────────────────┤
│ 하단 탭바 64px + 안전 영역               │  ← 고정 (홈·영웅·티어·맵·팀)
└───────────────────────────────────────┘
```

| 항목 | 값 | 이유 |
|---|---|---|
| 좌우 여백 | 16px | 모바일 표준 여백, 343px 콘텐츠 폭 확보 |
| 영웅 그리드 | **4열**, 간격 8px → 칸 약 80px | 이미지 ①의 6열(약 50px)은 한글 이름이 잘리고 손가락으로 누르기 작음. 80px이면 이름 4~5자 표시 가능 |
| 최소 터치 영역 | 44×44px | 모바일 접근성 권장 크기 |
| 하단 탭바 | 높이 64px + iOS 홈 표시줄 영역(`env(safe-area-inset-bottom)`) | 엄지가 닿는 위치 |
| 상단 바 | 56px, 스크롤 시 반투명 + 블러 | 콘텐츠를 가리는 면적 최소화 |
| 화면 회전 | 세로 고정 기준, 가로에서는 그리드 6열 | — |

## 4. 디자인 토큰

### 4-1. 기본 색상 (다크)

| 토큰 | HEX | 출처 | 용도 | 대비 (bg-surface 기준) |
|---|---|---|---|---|
| `bg-base` | `#08090A` | ② 추출 | 페이지 배경 | — |
| `bg-surface` | `#18181B` | ② 추출 | 카드, 표, 하단 시트 | — |
| `bg-elevated` | `#232328` | 조정값 | 그룹 헤더, 선택된 행, 입력창 | — |
| `bg-grid` | `#32313C` | ① 추출 | 영웅 그리드 영역 배경 | — |
| `line` | `#2A2A30` | ② 근사 | 행 구분선, 카드 테두리 | — |
| `text-primary` | `#F6F6F6` | ② 추출 | 이름, 숫자 | 16.4 : 1 |
| `text-secondary` | `#A1A1AA` | 조정값 | 보조 설명(역할·직업 줄) | 6.9 : 1 |
| `text-muted` | `#71717A` | 조정값 | 범례, 출처 문구 | 3.7 : 1 → **12px 이상 굵은 글자 또는 장식용만** |
| `accent` | `#5383E8` | ① 추출 | 활성 필터, 선택 배지, 링크 | 4.9 : 1 |
| `brand` | `#F0965A` | ② 추출 | 로그인 같은 주요 버튼(배경), 로고 포인트 | 버튼 글자는 **검정** 사용 (8.7 : 1). 흰 글자는 2.3 : 1로 불가 |

> `accent` 파랑 배경 위 흰 아이콘은 3.6 : 1입니다. 아이콘·굵은 큰 글자 기준(3 : 1)은 넘지만, 작은 본문 글자는 올리지 않습니다.

### 4-2. 데이터 색 (수치 종류별로 고정)

| 의미 | 토큰 | HEX | 출처 | 대비 | 사용 |
|---|---|---|---|---|---|
| 메타·지표 | `data-meta` | `#F0965A` | ② | 7.8 : 1 | 티어 점수 막대 |
| 픽률 (해당 시) | `data-pick` | `#00BAFC` | ② | 8.0 : 1 | 확장용 |
| 밴률·부정 | `data-negative` | `#FF5C7A` | 조정값 | 6.0 : 1 | 승률 50% 미만, 하락. ② 원본 빨강(#FC1E54, 4.6 : 1)은 막대에만 사용 |
| 승률·긍정 | `data-positive` | `#00BA78` | ② 추출 | 7.0 : 1 | 승률 50% 이상, 카운터 지수, 상승 |
| 막대 바탕 | `data-track` | `#2A2A30` | 조정값 | — | 막대의 빈 부분 |

**역할 색** — 아이콘과 그룹 헤더용 (어두운 배경 대비 확인값)
| 역할 | HEX | 대비 |
|---|---|---|
| 뱅가드 | `#60A5FA` | 7.0 : 1 |
| 듀얼리스트 | `#FB923C` | 8.3 : 1 |
| 전략가 | `#4ADE80` | 10.5 : 1 |

**티어 색** — 배지 배경 (글자는 항상 검정 `#08090A`)
`S #FF7F7F` · `A #FFBF7F` · `B #FFDF7F` · `C #FFFF7F` · `D #BFFF7F` · `F #7FBFFF` (엑셀 티어 색과 동일, 데스크톱 문서와 공통)

> **색만으로 구분하지 않습니다.** 승률 막대는 색과 함께 +/− 부호와 숫자를 붙이고, 역할은 아이콘을, 티어는 글자(S·A…)를 항상 표시합니다. 빨강·초록을 구분하기 어려운 사용자도 읽을 수 있습니다.

## 5. 컴포넌트

### 5-1. RoleFilterBar — 이미지 ① 필터 바
```
┌──────────────────────────────────────┐
│ [ ✱ ] [ 🛡 ] [ ⚔ ] [ ✚ ] [ ★ ]       │  ← 아이콘 5칸, 균등 분할
└──────────────────────────────────────┘
   전체   뱅가드  듀얼  전략가 즐겨찾기
```
- 각 칸 44×44px 이상, 활성 칸은 `accent` 배경 + 흰 아이콘
- 아이콘만 보이지만 `aria-label`("뱅가드")을 넣고, 처음 쓰는 사용자를 위해 아래에 작은 글자 라벨을 표시합니다(설정에서 끌 수 있음).
- 화면을 스크롤해도 상단 바 아래에 붙어 있습니다(sticky).
- 추가 필터(티어, P/D/R, 난이도)는 오른쪽 끝 [필터 ⚙] 버튼 → 하단 시트에서 고릅니다.

### 5-2. HeroGridItem — 이미지 ① 초상화
```
┌────────┐
│  ★     │ ← 즐겨찾기 배지 (accent 원형 18px)
│ [얼굴] │ ← 이미지 상단(얼굴)만 잘라서 정사각형
│      S │ ← 티어 미니 배지
└────────┘
 아이언맨
```
- 이미지: `image/Char/{slug}.png`(680×961)를 `object-fit: cover; object-position: 50% 12%`로 얼굴 부분만 보이게 자릅니다. 이미지를 따로 만들지 않아도 됩니다.
- 배경: `bg-elevated`에서 역할색이 15% 섞인 그라데이션. 투명 PNG 뒤에 은은하게 역할이 드러납니다.
- 누르면 → 영웅 미리보기 하단 시트, 길게 누르면 → 즐겨찾기 토글(진동 피드백은 지원 기기만).

### 5-3. StatRow — 이미지 ② 표의 한 행 (모바일용 재구성)
데스크톱의 5열 표는 모바일에서 읽을 수 없어서 **행 하나를 2단**으로 바꿉니다.
```
┌──────────────────────────────────────────┐
│ (아바타) 페니 파커            [S]  57.7% │  ← 1단: 이름 · 티어 · 핵심 수치
│          뱅가드 · P 포킹                  │
│ 승률 ━━━━━━━━━━━━━━━━━━│━━━━━━━          │  ← 2단: 50% 기준 양방향 막대
└──────────────────────────────────────────┘
```
- 승률 막대: 가운데가 50%, 오른쪽 초록(이상) / 왼쪽 빨강(미만). 이미지 ②의 승률 막대 방식입니다.
- 표시할 수치는 화면마다 1~2개로 제한합니다(티어 화면 = 승률, 카운터 = 지수).

### 5-4. GroupHeader — 이미지 ② 역할 그룹 줄
`(🛡) 뱅가드 · 14명                 더 보기 ›` — `bg-elevated` 배경, 높이 40px. 처음에는 상위 5명만 보이고, 더 보기를 누르면 펼쳐집니다(이미지 ②의 Top 5 방식).

### 5-5. DeltaBar — 이미지 ② Trending 막대
카운터 지수처럼 0을 기준으로 크고 작음이 있는 값에 씁니다.
`스파이더맨  ━━━━━━━━━━━━  +16.2` (초록) · 값이 음수면 빨강, 왼쪽 방향.

### 5-6. 기타
| 컴포넌트 | 디자인 |
|---|---|
| BottomTabBar | 홈 · 영웅 · 티어 · 맵 · 팀 (아이콘 + 11px 라벨). 활성 탭은 `accent` 아이콘 + 굵은 라벨 |
| BottomSheet | 영웅 미리보기·필터용. 위쪽 손잡이 막대, 아래로 끌어 닫기, 높이 60% → 위로 끌면 전체 |

## 6. 화면별 설계 (모바일)

- 이미지 ②의 "지금 메타" 구성을 세로로 옮겼습니다. 데이터는 엑셀 "티어 목록" 시트입니다.

### 6-2. 영웅 목록
`RoleFilterBar` + 검색창 + `HeroGridItem` 4열 그리드 (이미지 ① 구성). 카드를 누르면 미리보기 하단 시트가 열립니다: 큰 이미지 · 이름 · 티어 · 승률 막대 · 태그 · [상세 보기].

### 6-3. 영웅 상세
| 순서 | 구역 | 스타일 |
|---|---|---|
| 1 | 히어로 | 전신 이미지(화면 높이 45%), 아래로 `bg-base`로 사라지는 그라데이션, 이름 `title-lg` + 원문 이름 + 역할·티어 배지 |
| 2 | 핵심 수치 | 체력 · 난이도 · 궁극기 비용을 3칸 카드로 |
| 3 | 탭 | SegmentTabs: 스킬 · 상성 · 협공 · 성향 (화면 위에 고정) |
| 4-스킬 | 스킬 카드 목록 | 이름 + 키 칩 + 쿨타임 칩, 누르면 세부 수치 펼침 |
| 4-상성 | DeltaBar 목록 | "이 영웅을 잡는 영웅" TOP5 + "강한 상대" 아바타 3개 + SourceChip |
| 4-성향 | P/D/R | 막대 3개(가로) — 작은 화면에서는 레이더보다 막대가 읽기 쉬움 |

### 6-4. 티어
GroupHeader(티어 S~F) + StatRow. 상단에 역할 SegmentTabs. 승률 막대로 같은 티어 안의 차이를 보여줍니다.

### 6-5. 맵
SegmentTabs(경쟁 · 호송 · 경쟁+호송) + 맵 행(이미지 ②의 Map Meta 형태): 썸네일 · 맵 이름 · 지역 · 출시 시점 · 1위 영웅 아바타와 승률. 누르면 TOP5 펼침.

### 6-6. 팀 빌더
- 위쪽 고정: 슬롯 6칸(정사각 48px, 가로 한 줄) + 팀 성향 요약 한 줄 ("다이브 중심 · 협공 2개")
- 가운데: `RoleFilterBar` + 4열 그리드. 선택된 영웅은 흐리게 + ✓ 배지(이미지 ①의 잠금 배지 위치)
- 아래: [분석 보기] 버튼 → 하단 시트에 P/D/R 막대, 협공 목록, 카운터 추천

```tsx
// 승률 양방향 막대 (50% 기준)
function WinRateBar({ rate }: { rate: number }) {
  const diff = Math.min(Math.abs(rate - 50) * 10, 50); // ±5%p를 막대 절반으로 (표시 배율)
  const up = rate >= 50;
  return (
    <div className="relative h-1 rounded-full bg-data-track" role="img"
         aria-label={`승률 ${rate}% (50% ${up ? '이상' : '미만'})`}>
      <span className="absolute inset-y-0 left-1/2 w-px bg-text-muted" />
      <span className={`absolute inset-y-0 rounded-full ${up ? 'left-1/2 bg-data-positive' : 'right-1/2 bg-data-negative'}`}
            style={{ width: `${diff}%` }} />
    </div>
  );
}
```

> v3를 쓰면 같은 값을 `tailwind.config.ts`의 `theme.extend.colors`에 넣으면 됩니다. 설치한 버전의 공식 문서에 맞춰 주세요. 막대 배율(±5%p = 막대 절반)은 이 데이터의 승률 범위(약 45~58%)에 맞춰 정한 값이라, 데이터가 바뀌면 조정해야 합니다.
