## 1. 디자인 콘셉트

### "게임 속 도감 × 깔끔한 데이터 대시보드"

| 영역 | 참고 이미지 | 가져올 느낌 | 쓰는 곳 |
|---|---|---|---|
| **보는 영역** (영웅 카드, 이미지, 선택 상태) | ① 게임 히어로 선택 화면 | 기울어진 카드, 사선 장식, 남색 + 노란 포인트, 게임 몰입감 | 홈, 영웅 목록, 영웅 상세 상단, 팀 빌더 슬롯 |
| **읽는 영역** (수치, 표, 상세 정보) | ② 데이터 테이블 + 상세 패널 | 흰 배경, 얇은 구분선, 넉넉한 여백, 둥근 패널, 알약 모양 태그 | 스킬 표, 카운터 목록, 티어 표, 비교, 맵 정보 |

**이렇게 섞는 이유:** 도감 사용자는 영웅을 **고를 때**와 수치를 **비교할 때** 원하는 것이 다릅니다.
- 고를 때: 게임 화면처럼 이미지가 크고 익숙해야 빨리 찾습니다.
- 비교할 때: 장식이 없고 줄이 맞는 표가 읽기 쉽습니다.

그래서 화면 위쪽(탐색)은 게임 감성, 아래쪽(정보)은 대시보드 감성으로 나눕니다.

## 2. 참고 이미지 분석

### 2-1. 이미지 ① 게임 히어로 선택 화면

| 관찰한 요소 | 특징 | 도감 적용 |
|---|---|---|
| 상단 바 | 짙은 회색(#2F3237 근사) 바, 왼쪽 로고 + 탭 메뉴, 활성 탭은 밝게 강조 | 글로벌 헤더 |
| 서브 탭 | "히어로 / 협공" 작은 알약형 탭 | 영웅 상세의 스킬 탭, 맵의 모드 탭 |
| 배경 | 밝은 라벤더 블루(#D9E1F4 근사) 면 위에 남색(#2F305B 근사) 사선 띠가 화면 모서리를 가름 | 히어로 섹션 배경. CSS `clip-path`로 사선 구현 |
| 영웅 카드 | 세로형(약 3:4), **오른쪽으로 살짝 기운 평행사변형**, 캐릭터가 카드 위로 살짝 튀어나옴 | `HeroCard` 컴포넌트의 핵심 형태 |
| 이름 라벨 | 카드 하단 어두운 보라 회색 띠(#353346 근사) + 흰 글자 + 오른쪽 역할 아이콘 | 카드 하단 라벨 |
| 선택 상태 | 선택 카드만 크게 확대되고 **노란 테두리(#F8E040 근사)**와 노란 사선 장식 | hover / 선택 상태 |
| 필터 | 우측 상단 "전체 포지션" 드롭다운 | 역할 필터 |
| 정렬 | 7열 그리드, 2행째는 반 칸 엇갈림 | 데스크톱 그리드 (엇갈림은 선택 사항) |

### 2-2. 이미지 ② 데이터 테이블 + 상세 패널

| 관찰한 요소 | 특징 | 도감 적용 |
|---|---|---|
| 배경 | 거의 흰색(#FAFAFB) 위에 흰 카드 | 정보 영역 기본 배경 |
| 테이블 | 열 제목은 작은 회색 글씨, 행 사이 얇은 회색 선, 세로선 없음 | 스킬 표, 카운터 표, 티어 표 |
| 강조 수치 | 초록 아이콘 + 초록 숫자(#30B18C 근사) "82.5%" | 승률·카운터 지수 강조 |
| 아이콘 행 | 작은 원형 아이콘을 가로로 나열 | 카운터 영웅 아바타 나열, 협공 파트너 |
| 보조 버튼 | 회색 테두리 알약 버튼 "확인" | "상세 보기", "비교에 추가" |
| 상세 패널 | 오른쪽에 둥근 흰 카드: 프로필 이미지 → 이름 → 부제 → 설명(회색) → 위치 → 태그 → 큰 알약 버튼 | 영웅 목록에서 카드를 누르면 열리는 **미리보기 패널** |
| 태그 | 연한 회색 배경의 알약 태그 | 역할, 주 성향(P/D/R), 폼/모드 태그 |
| 여백 | 행 높이가 넉넉함(약 52px), 패널 안쪽 여백이 큼 | 표 행 높이, 패널 패딩 |

## 3. 디자인 원칙

1. **이미지는 크게, 정보는 차분하게.** 영웅 이미지가 주인공입니다. 정보 영역은 장식을 줄입니다.
2. **노란색은 '지금 선택한 것'에만.** 게임처럼 노랑 포인트는 선택·활성 상태 하나에만 씁니다. 여기저기 쓰면 강조 효과가 사라집니다.
3. **색만으로 의미를 전하지 않습니다.** 역할·티어·성향은 색과 함께 글자나 아이콘을 항상 표시합니다.
4. **출처는 조용하지만 분명하게.** 커뮤니티 통계 옆에는 작은 회색 출처 문구를 항상 붙입니다.

## 5. 컴포넌트 디자인

### 5-1. HeroCard (영웅 카드) — 이미지 ① 기반
```
   ╱‾‾‾‾‾‾‾‾‾‾‾╱
  ╱  [캐릭터]   ╱   ← 이미지가 카드 위쪽 경계를 살짝 넘음 (overflow: visible)
 ╱   투명 PNG  ╱
╱▓아이언맨  ⚔ ╱    ← 라벨 띠 #353346 + 흰 글자 + 역할 아이콘
‾‾‾‾‾‾‾‾‾‾‾‾‾
 [A] [P]            ← 카드 아래 티어·성향 배지 (목록에서만)
```
| 상태 | 표현 |
|---|---|
| 기본 | 흰색~라벤더 그라데이션 배경 + 캐릭터 상반신 (`object-position: top`) |
| hover | 카드가 4px 위로 올라가고 이미지가 1.05배 확대 (200ms) |
| 선택됨 | 노란 테두리 3px + 오른쪽 위 노란 사선 장식 + 1.08배 확대 (게임과 동일한 피드백) |
| 키보드 포커스 | 선택과 같은 노란 테두리 + 바깥쪽 남색 포커스 링 |
| 비활성 (팀 빌더에서 이미 선택) | 흑백(`grayscale`) + 투명도 40% |

- **구현 메모:** 카드 틀만 `skewX(-6deg)`로 기울이고, 안쪽 이미지와 글자는 `skewX(6deg)`로 되돌려 똑바로 보이게 합니다.
- 이미지는 `image/Char/{slug}.png`(680×961 투명 PNG)를 `next/image`로 불러옵니다. 목록 카드에는 `sizes`를 지정해 작은 크기만 받게 합니다.

### 5-2. HeroPreviewPanel (영웅 미리보기 패널) — 이미지 ② 상세 패널 기반
```
┌───────────────────────────┐
│        [원형 아바타]         │
│         아이언맨             │
│   Iron Man · 듀얼리스트      │
│                             │
│  궁극기 무적의 펄스 캐논...   │  ← 회색 설명 3줄 말줄임
│                             │
│  체력 250 · 난이도 ★★☆☆☆     │
│  [A티어 51.6%] [P 포킹] [폼 없음] │ ← 알약 태그
│                             │
│  (     상세 보기  →     )   │  ← 큰 알약 버튼
└───────────────────────────┘
```
- 데스크톱: 영웅 목록 오른쪽에 고정(폭 360px). 카드를 누르면 내용만 바뀝니다.
- 모바일: 하단에서 올라오는 시트(bottom sheet)로 표시합니다.
- **이유:** 영웅을 하나씩 상세 페이지로 들어갔다 나오지 않아도 훑어볼 수 있습니다. 이미지 ②의 "목록 + 오른쪽 상세" 구조가 이 탐색 방식에 맞습니다.

### 5-3. DataTable (표) — 이미지 ② 테이블 기반
| 규칙 | 값 |
|---|---|
| 카드 | 흰 배경, `radius-panel`, 테두리 `line-100` |
| 표 제목 줄 | 카드 왼쪽 위에 아이콘 + 굵은 제목 (예: "↗ 이 영웅을 잡는 영웅") |
| 열 제목 | `caption`, `ink-600`, 대문자·굵기 없음 |
| 행 | 높이 52px, 아래쪽 1px `line-100`, hover 시 `surface-50` |
| 세로선 | 사용하지 않음 |
| 숫자 열 | 오른쪽 정렬, `tabular-nums` |
| 강조 숫자 | `positive` 색 + 위쪽 화살표 아이콘 (예: ↑ +16.2) |

**적용 표:** 스킬 표(이름 · 키 · 쿨타임 · 세부 수치), 카운터 TOP5(아바타 · 이름 · 지수 · 유형 · 상세 보기 버튼), 티어 표, 비교 표, 맵 승률 TOP5

### 5-4. 기타 컴포넌트
| 컴포넌트 | 디자인 |
|---|---|

## 7. 모션

| 상황 | 동작 | 시간 |
|---|---|---|
| 카드 hover | 위로 4px + 이미지 1.05배 | 200ms, ease-out |
| 카드 선택 | 1.08배 + 노란 테두리 나타남 | 150ms |

## 9. 접근성 체크리스트

- [ ] 본문 글자 대비 4.5 : 1 이상 (4-1, 4-2 표 기준값 사용)
- [ ] 노란색(`accent-yellow`)은 흰 배경 위 글자에 쓰지 않음
- [ ] 티어·역할·성향은 색 + 글자/아이콘 함께 표시
- [ ] 영웅 이미지 `alt`에 영웅 이름("아이언맨 전신 이미지")
- [ ] 카드·필터·탭 모두 키보드로 이동·선택 가능, 포커스 링이 보임
- [ ] 필터 버튼 `aria-pressed`, 탭 `role="tablist"`, 미리보기 패널 `aria-live="polite"`
- [ ] 레이더 차트 옆에 숫자 칩을 함께 두어 차트를 못 읽어도 값을 알 수 있음
